# ES 119 · Principles of Artificial Intelligence (2026)

Course website for ES 119 Principles of Artificial Intelligence at IIT Gandhinagar, Semester II 2025–26:
<https://nipunbatra.github.io/principles-ai-26/>

The site is a [Quarto](https://quarto.org) website in the same design as
[ES 667 Deep Learning](https://nipunbatra.github.io/dl-2026/). GitHub Actions renders it into `docs/` and publishes it
to GitHub Pages on every push to `main`.

| File | Contents |
|---|---|
| `index.qmd` | Home: course facts, course record, module overview, key questions, questions, references |
| `schedule.qmd` | Lectures: one row per lecture with slides, short videos, notebooks and demos |
| `assessment.qmd`, `_dates.qmd` | Grading, attendance, policies and dates |
| `grading.qmd`, `course-contents.qmd` | Redirects from the old Grading and Course Contents pages |
| `styles.scss`, `course.scss` | Shared theme (`styles.scss` is identical to dl-2026) and small additions |
| `rail.html`, `course-theme.html`, `course-tools.html` | Side rail, light and dark switch, footer, copy-link buttons and date handling |

Preview locally with `quarto preview`.
